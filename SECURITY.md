# Security policy

## Reporting a vulnerability

Report it privately through GitHub: the repository's **Security** tab, **Report a vulnerability**. Please do not
open a public issue for it. If private reporting is unavailable, open an issue that only asks for a contact, without
details.

Include the version (the release tag or commit), what an attacker can do, and how to reproduce it. Fixes ship in a
release; say whether you want to be credited in its notes.

## Supported versions

Only the latest release gets security fixes. Servers should update to it.

## Scope

What the server exposes and what it protects against is described in
[docs/systems/security.md](docs/systems/security.md). Issues in the game client itself, or in services this project
does not run, are out of scope.
