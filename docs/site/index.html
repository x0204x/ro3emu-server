FROM READING TO BUILDING

Start with the code.

With the .NET 10 SDK, you can clone and build the server without a game client.

To play, download RO3Emu.exe from the latest release and run it: it finds your Ragnarok 3: Genesis game (or downloads it from the official servers), prepares the data and starts the server and the game. Nothing else to install.

How to play and host ↗
BUILD THE SERVER
git clone https://github.com/aethai/ro3emu-server.git
cd ro3emu-server
dotnet build src/Ro3Emu.Server -c Release

Builds server code. Playing requires exported client data.

Before you begin

Which game and client does RO3Emu target?

The Ragnarok Online 3 PC client, also called RO3 and ROO_PC in the setup instructions. This project targets that client's protocol. For supported setup details, start with the README.

What is included in the repository?

Server and tool source code, protocol definitions, documentation and tests. The game client, exported game data and game artwork are not included. A playable setup requires your own client and the data export described in the guide.

Can I contribute without the game client?

Yes. Start with documentation, the server build or client-independent tooling. Some end-to-end tests and all in-game validation require exported client data. The contribution guide explains the distinction.

Is this an official Ragnarok project?

No. RO3Emu is an independent research and interoperability project, unaffiliated with Gravity or any Ragnarok publisher. Ragnarok Online is a trademark of Gravity Co., Ltd.
