# 2026-10-30 玩家端修正

登入器 2.0.12 會在確認遊戲成功啟動後自動關閉。需要多開時重新開啟登入器，會偵測選定安裝目錄中仍在執行的遊戲；每台電腦最多四開。第五個會被客戶端名額鎖阻擋，關閉其中一個後可再次開啟。啟動失敗時保留登入器並顯示錯誤。

登入器尚未關閉時，失焦、最小化或切換頁面會停止裝飾動畫；橫幅重用有限的圖片快取，避免持續建立圖片與動畫時鐘。遊戲執行期間禁止更新、修復或切換安裝目錄。

繁中介面會優先使用客戶端原生繁體中文，不再被舊有中文轉英文對照表改成 Backpack、Skills 或 Trade。補譯跟隨玩家目前的語言選擇，不寫入或強制變更選語設定；原生有效的文字 ID 譯文優先，只有缺字才使用對應補譯。文字 ID 配對檔與字串檔一同交付，保留同字異義及格式參數。

自行透過 RO3Emu 安裝或加入伺服器時，會從玩家自己的三語資料建立顯示快取，以來源與輸出雜湊判斷是否過期。完整自訂繁中配對檔會保留；缺少其中一檔時會在修補 DLL 前停止並顯示原因。

頭銜面板改為獨立置中視窗，等比縮放並保留邊界與關閉列，關閉時還原原生元件。補上原生升級失敗處理的註冊，交由既有錯誤處理解除等待狀態；保留既有成功、錯誤處理與初階設定數值。

驗證包括繁中補譯與切語系 11 項測試、安裝／語系／補丁相關 29 項測試、登入器相關 18 項測試，以及語系、頭銜與組隊相關 36 項測試。須有原生客戶端的安裝端到端測試另列略過；實際玩家的視窗排序、動畫、切語系與連續多開仍待驗收。另以獨立測試程序驗證 Windows 四個名額、第五個拒絕及程序結束後釋出，不啟動遊戲。

本次沒有新增尚未取得權威來源的任務 producer、OPCODE 欄位或原服組隊分帳規則。相關未知項目維持研究文件中的狀態，不能把測試通過視為原服玩法已完整重現。
